# 本草知问 · 中药知识库问答

当前代码快照：**V1.1（2026-10-31）**，对应 [GitHub V1.1 分支](https://github.com/17346733172/zhongcao/tree/V1.1)。

面向整理中药资料并据此提问的用户。按用户最新 DeepSeek 排版参考采用浅灰侧栏、白色主区和统一无衬线字体，提供 **Python / FastAPI 后端、真实登录、角色权限和 DeepSeek 资料问答**。

## 当前功能

- 账号密码登录、退出、个人改密；登录会话默认有效 8 小时。
- 管理员创建账号、分配角色、停用 / 启用账号、重置密码。无公开注册，无默认密码。
- MD / TXT 文本保存到 SQLite 共享知识库，刷新和服务重启后仍可读取。
- 未勾选「原文检索」时直接使用 DeepSeek 自身知识和同模式对话回答，不加载、检索或发送知识库资料。无需知识库命中即可回答，不生成文档引用或「资料依据」标签。验证见[普通 AI 与知识库隔离验收](docs/NO-KNOWLEDGE-QA.md)。
- 勾选「原文检索」后，在正式中药基础文档与共享文本中关键词检索，优先根据检索资料回答；资料之外的一般知识单独标为「AI 补充，非文档原文」，不挂文档引用，并附加原文摘录。此模式未命中的自然语言可先由模型整理口语 / 错字后重检，仍无资料时不生成回答；数字无意义输入不调用模型，不返回无关片段或示例引用。
- 两种模式分别支持当前会话追问：先问「陈皮」再问「作用？」会承接陈皮；明确换药材时切换主题，新建对话使用空上下文。知识库模式下对「有什么不要的药效吗」这类口语错字追问，可结合上文理解为当前药材的不良反应 / 禁忌，页面显示整理后的问题；意思不明确时先澄清。
- 点击发送或按 Enter 默认普通 AI 回答；「原文检索」开启后使用知识库问答并附加独立原文结果。两种模式的追问历史分别保留最近 5 轮，避免取消勾选后带入此前的知识库回答。资料加载失败不阻止普通 AI 提问。
- 未开启「原文检索」时，AI 回答隐藏引用资料区域与正文引用编号；开启后才显示。每轮记录发送时的选择，切换开关不改变已生成的回答。验证见[引用展示验收](docs/SOURCE-VISIBILITY-QA.md)。
- 勾选原文检索时，AI 回答下方不再重复展示引用资料卡片，仅保留下方原文结果中的资料卡片；AI 正文引用编号可直接打开对应原文。验证见[引用卡片去重验收](docs/SINGLE-SOURCE-CARD-QA.md)。
- 普通 AI 回答保留总标题，勾选原文检索后的 AI 回答隐藏总标题，复制同步；去掉模型名和重复生成说明，保留正文分节、追问理解提示、引用、AI 补充标签和原文结果标题。验证见[回答头部验收](docs/ANSWER-HEADER-QA.md)。
- 「你好」等纯问候在页面直接显示一条欢迎回复，不调用模型或资料检索，不占用追问历史；问候后带实际问题时正常查询。开启附加原文时仅展示有内容的结果：AI 未命中但原文命中时只显示原文，反向只显示 AI；两边均未命中时只显示一条提示，两边都有内容时分别展示。
- 当前页历史会话、原文查看、复制；引用区域与回答卡片左边缘对齐，适配桌面和手机。生成失败保留问题，切换会话取消旧请求。
- 点击左侧「中药基础资料」阅读用户提供的《中药基础知识（详解版）》全文，保留章节、段落与 7 张表格，支持章节定位和 Word 原文件下载；保留当前对话与草稿。正文与下载均需登录。

| 角色 | 查看资料与提问 | 添加 / 移除资料 | 创建账号与分配权限 |
| --- | --- | --- | --- |
| 普通用户 viewer | 是 | 否 | 否 |
| 编辑员 editor | 是 | 是 | 否 |
| 管理员 admin | 是 | 是 | 是 |

权限由 FastAPI 每次请求校验。角色调整、账号停用和密码重置会撤销该账号的所有旧会话；修改自己的密码后也需要重新登录。

**当前支持普通 DeepSeek 问答，以及勾选原文检索后的关键词 RAG。** 向量语义检索、通用 PDF / Word 上传解析、会话持久化、流式回答和线上部署仍待接入。已保存文本供本系统所有登录用户查看，暂不区分个人知识库或租户。

## 处方检查 Agent

登录后点击左侧「处方检查」。支持 TXT、MD、DOCX、PDF、PNG、JPG、WEBP，每次一份处方，单文件 10 MB，PDF 最多 8 页；也可粘贴文字或手动录入。

后端使用 **LangGraph** 编排读取、意图识别、结构化提取、人工核对、规则检查和报告。图片与扫描 PDF 通过本地 RapidOCR 识别，文字经现有 DeepSeek 配置识别意图并提取字段；非处方或多个处方版本会要求补充。用户逐项核对药名、剂量、单位与每剂量口径后才能检查，修改后需再次确认。

按用户已明确的要求，处方默认按「每一剂的量」检查。上传与核对页显示「本方剂量口径」：选择随提取请求、药物表格、后端检查和报告完整传递，新增药行继承当前口径；不再要求额外点击每剂量确认按钮。药量数字不变，仍须核对原文后勾选确认；可改为总量或逐味设置。

信息不完整时，3.1 结论下会直接列出本次需补充的具体项目，例如患者年龄、过敏史，或第几味药的剂量、单位、口径；已提供的字段不重复要求补充。点击「去补充信息」可保留已有数据并定位第一个缺失字段，补充后再次确认检查，已补齐项自动从清单移除；复制报告也包含该清单。仍可通过「修改数据后复查」调整其他数据。

报告按用户给出的五节审核意见格式输出：**3.1 审核结论、3.2 主要问题、3.3 毒性药材与煎法核查、3.4 其他核查、3.5 处理建议**。结论加粗，正文使用条目，处理建议使用编号及子项；去掉原来的计数、卡片、明细折叠与范围面板。内容按当前处方生成，复制为同样的 Markdown 分节正文；格式及验证见[分节报告验收](docs/PRESCRIPTION-REPORT-QA.md)。3.1 由系统直接给出「通过 / 不通过 / 待补充信息」及具体判断依据。已接入十八反、人参—五灵脂十九畏、采用参考剂量和特殊煎法；普通用药提醒不自动阻断通过。新增依据与示例验证见[系统判定验收](docs/PRESCRIPTION-DECISION-QA.md)。

检查基本信息缺失、非法数值、单位、重复饮片、有限十八反配伍、部分特殊煎法及本地资料参考剂量。报告附依据与复核提示，支持复制；「通过」只表示本次已确认数据在系统覆盖项目内通过辅助审核，不代表完整临床安全评估或实际调配授权。尚未接入完整现行药典数据库、全部十九畏 / 妊娠禁忌、西药相互作用及诊断适宜性审核。

处方不写入共享知识库，不持久化原文件或报告；关闭弹窗后需重新上传。上传页说明模型处理范围；明显姓名、号码等字段会在发送模型前作基础遮盖，但仍应由用户先脱敏。无需新增模型密钥，复用后端 DeepSeek 配置；未配置时可手动录入并运行数据检查。依赖安装使用 requirements.txt 指定的官方 PyPI，OCR 模型随依赖提供，无需另行配置图片识别服务。详见[处方 Agent 说明与验收](docs/PRESCRIPTION-AGENT.md)。

## 页面排版

桌面采用可收起侧栏与白色聊天区。新会话显示居中的欢迎语和圆角多行输入框，发问后输入框移至底部；右上角「知识库资料」打开共享资料抽屉：管理员 / 编辑员可上传、查看、移除资料，普通用户可查看；抽屉不再重复提供处方入口。入口分工及验证见[资料入口验收](docs/KNOWLEDGE-ENTRY-QA.md)。回答、标题与正文统一无衬线字体，引用和 AI 补充标识保留。手机提供导航与资料抽屉。视觉参考与验收见 [设计规范](DESIGN.md) 和 [视觉验收](design-qa.md)。

账号区、知识库 / 历史标签、顶部标题、上传按钮与底部说明按最新字体参考统一使用本地 DM Sans 搭配系统中文字体；主标签桌面 18px、手机 16px，辅助文字 14px，均采用常规字重。字体文件与开放许可位于 frontend/public/fonts，页面无需连接外部字体服务。

回答正文按用户提供的 DeepSeek 截图调整为 16px、1.75 行高，标题采用清晰的加粗层级，阅读列最大宽度 800px；来源小标签与标题同排。生成正文支持段落、加粗、列表、引用、代码和表格，原文摘录保持原字面文本；窄屏表格可单独滚动，复制保留 Markdown 与来源标识。普通 AI 和知识库模式均向模型说明按需使用这些排版，不改变资料与 AI 补充的边界。对照与验证见 [视觉验收](design-qa.md)。

## 前后端分离

- `frontend/`：Next.js / React / TypeScript，负责登录、知识库和账号管理界面，独立安装依赖和启动。
- `backend/`：Python / FastAPI，负责认证、权限校验、账号和资料 API 及 SQLite，独立安装依赖和启动。
- 前后端通过 HTTP API 通信；本地由 Next.js 将 `/api/*` 同源代理到 FastAPI，业务逻辑和数据库访问集中在后端。前端通过服务端 `BACKEND_URL` 配置后端地址。

## 本地运行

环境：Python 3.11+、Node.js 20.9+、pnpm 11。

1. 双击根目录 **启动后端.cmd**。首次运行会建立独立虚拟环境、安装依赖，并提示设置管理员账号与密码（至少 10 位，输入时不显示）。保持终端开启。
2. 双击 **启动前端.cmd**，保持终端开启。
3. 打开 [登录页面](http://127.0.0.1:3000/login)，使用刚设置的账号登录。从左下角「账号管理」创建其他账号并分配角色。

两个脚本均支持 `--check` 检查运行环境。后端接口文档：[Swagger UI](http://127.0.0.1:8000/docs)。写接口需要 `X-CSRF-Protection: 1` 请求头；浏览器客户端已自动携带。

手动启动后端：

```powershell
cd D:\本草\backend
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m app.cli create-admin
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-proxy-headers
```

另一终端启动前端：

```powershell
cd D:\本草\frontend
pnpm install --frozen-lockfile
pnpm dev
```

可将 backend/.env.example 复制为 backend/.env 修改数据库位置、允许来源及 Cookie 配置；启动时自动读取，已有系统环境变量优先。frontend/.env.example 可复制为 frontend/.env.local 修改服务端 `BACKEND_URL`，修改后须重启开发服务或重新构建。不要将密码和实际 .env 提交到 Git。

## 配置 DeepSeek

将 backend/.env.example 复制为 backend/.env，在本机填写 DEEPSEEK_API_KEY；不要在聊天或源码中发送密钥。默认 DEEPSEEK_BASE_URL=https://api.deepseek.com、DEEPSEEK_MODEL=deepseek-flash，均可由后端配置。保存后重启后端，刷新页面；发送默认使用 AI 回答，无需选择按钮。未配置时显示配置提示，请求失败保留草稿。

密钥仅在后端读取。未勾选原文时只发送当前问题及普通 AI 模式最近 5 轮受限摘要，不发送资料、文件名或知识库模式的历史回答。勾选后发送当前问题、知识库模式最近 5 轮摘要及最多 3 个检索片段；未命中的自然语言可能先单独进行语义整理，再重检资料（额外一次模型请求）。每轮摘要的问题最多 500 字符、回答最多 1000 字符；每个片段最多 3000 字符。后端接受 `use_knowledge` 布尔开关（默认 false），仅在 true 时读取授权知识库并校验来源编号；客户端不能指定资料、模型或密钥。文档段须有有效引用，AI 补充段无文档引用；普通 AI 回答无文档来源。两种模式均未接入联网搜索，模型知识未联网核实。

配置与接口细节见 [开发说明](docs/DEVELOPMENT.md)，验证记录见 [DeepSeek 接入验收](docs/DEEPSEEK-QA.md) 、[混合回答验收](docs/HYBRID-ANSWER-QA.md) 和 [多轮与口语追问验收](docs/FOLLOW-UP-QA.md)。

## 资料使用边界

单个文本文件最多 10 MB，采用 UTF-8 编码。空文件、超限、无权限和保存失败有明确反馈。PDF / Word 显示「未上传 · 待接入解析服务」，不会伪造成功。

内置基础资料由指定 Word 原文件一次性导入，独立于右侧上传列表；通用 Word 上传解析仍待接入；内置资料支持阅读、下载和关键词原文检索。更新内置资料的方法见 [开发说明](docs/DEVELOPMENT.md)。

发送默认直接调用 DeepSeek，不使用知识库；开启「原文检索」后才检索真实资料并按 AI 整理的完整问题（未整理时使用当前输入）附加原文摘录。资料只在勾选或主动查看资料时加载。知识库模式的功效等明确字段问题会聚焦对应内容，炮制 / 饮片问题会一并查找相关总论章节，未命中不调用回答生成。当前关键词匹配尚不等同于向量语义检索。首页不预置模拟文件或陈皮回答，检索结果只引用真实资料。回归记录见 [检索修复验收](docs/RETRIEVAL-QA.md)。聊天记录只在当前页面内保留，退出或刷新后清除；追问上下文按发送模式隔离。
