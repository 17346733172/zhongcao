# 构建与部署

## 当前状态

当前为本地 Next.js 前端原型，没有发布到线上。服务只监听 127.0.0.1，不对局域网或公网开放。

## 本地生产运行

在 frontend 目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

若开发服务已占用 3000 端口，先结束开发服务，再启动生产服务。

## 托管准备

选用支持 Next.js 16 和 Node.js 20.9+ 的环境，设置应用根目录为 frontend、构建命令为 pnpm build。当前未配置静态导出，不应直接把 .next 当作普通静态站点目录上传。

如果接入 AI 或文件解析服务，应另行配置服务端环境变量、存储、访问控制和真实文件限制。当前前端不需要 API 密钥。

## 发布验收

检查根页面、资源、移动布局、主要交互及控制台。发布后的演示功能仍需保留相应标识。记录源码版本、真实访问地址和回退方式。

只有用户明确请求发布或分享时才执行线上部署。
