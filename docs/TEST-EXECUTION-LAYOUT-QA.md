# 测试执行布局验收

日期：2026-11-14。

后续新建入口已启用并打开全局仿真控制弹窗，见[新建入口验收](NEW-TEST-TASK-QA.md)；以下为初次布局交付时的验证。

按用户截图搭建布局，用户明确表示内容后续补充。当前任务是页面结构与交互占位，不接入测试服务、不复制截图任务或测试结果。

## 页面范围

- 顶部保留测试执行、说明、导出结果表、新建测试任务。
- 执行中、历史批次、测试记录三个标签可点击，并支持左右、Home / End键。
- 执行中显示两处明确标注的任务布局区域，保留状态 / 批次标签、方案信息、报告 / 停止按钮、数量和结果摘要、进度条位置、机台 / 槽位位置。
- 下方显示实时测试记录表头；全部记录切换至测试记录标签。历史批次与测试记录显示各自表头和空状态。
- 布局预览始终有明确说明；数量为待补充符号，没有真实任务、进度、计数或测试结果。新建、停止、报告、导出使用原生disabled并说明原因，没有虚假的成功反馈。

## 验证

- `frontend` 中 `pnpm typecheck` 通过，`pnpm test` 的33项既有回归通过。
- 源码隔离副本运行 `pnpm build`，最终版本编译、TypeScript与六个静态页面生成通过。
- 最终生产版本3217端口，1630×869、1440×869、390×1000、320×1000、deviceScaleFactor=1，四种尺寸均通过。1630宽度对应用户参考图。
- 三个标签、全部记录、Home / End / 左右键、模态焦点约束、Escape关闭、焦点返回与问答草稿保留通过；六个业务操作按钮均禁用，未显示任何测试记录数据行。
- 页面、弹窗、内容区均无整体横向溢出。手机表格独立滚动，待补充说明位于宽表格之外，保持可见。
- 无浏览器运行错误；没有测试、仿真、聊天或模型接口调用。浏览器登录 / 文档响应是隔离的模拟账号与资料，不写生产账号或知识库。
- 内置浏览器连续两次报告进程退出，改用项目既有的无头Chrome / Playwright界面验收流程。临时生产服务在验收后关闭；日常3000端口开发服务保留。
