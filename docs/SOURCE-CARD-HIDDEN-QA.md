## 回答缓慢的只读检查

本机为 i5-10200H、8 GB 物理内存。检查时 CPU 占用约 19%，可用物理内存约 0.75–0.9 GB，系统提交内存约 26.1 GiB；PagesInputPersec 为 13,424、PageReadsPersec 为 2,977，存在明显内存换页压力。本地 Qwen 模型使用 CPU / float32，容易受内存与磁盘换页影响。

此前真实 Qwen 检查中，独立进程首次加载加检索约 68.39 秒，后续检索约 0.32–0.74 秒，见 [RAG 验收](RAG-QA.md)。当前链路先本地检索，必要时整理问题后重检，再等待 DeepSeek 返回完整 JSON，前端一次性展示，尚无流式显示。
