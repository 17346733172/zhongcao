# 项目定位与范围

更新：2026-10-28。

为整理中药资料并据此提问的用户提供知识库问答界面，帮助他们组织资料、阅读回答并回到原文核对引用。

## 已确认

- 数据中心提供今天、近7天、近30天及自选起止日期的业务事件统计和每日明细；按北京时间自然日包含起止两天，一次最多366天，结束日不晚于今天。新处方 / 新批次 / 完成 / 配发 / 报警按真实发生日期计算，设备当前状态仍单独展示。只能统计平台已留存记录，历史缺口不得补造为零。暂不提供历史设备利用率或跨实例合并。

- 左侧功能导航保留中药资料与处方、数据中心，以及测试、智能、设备与系统分组（六个栏目等待用户提供内容）；运行总览放在数据中心内，与概览、设备与异常、全部处方并列。中间保留问答及引用，资料通过右侧抽屉查看。侧栏不再显示新建及历史会话入口。
- 浅色、简洁、蓝色，沿用第 3 张设计，适配电脑和手机。
- 前端 Next.js 16、React 19、TypeScript。
- 后端采用 Python / FastAPI；提供登录界面，不同账号具有不同权限。

## 当前范围

2026-11-14：测试执行的新建任务弹窗可生成匿名演示批次（1–50）、开始和暂停当前配置的煎药流程仿真。沿用处方上传的登录范围（所有具有knowledge:read权限的角色），写请求必须通过CSRF；不控制真实设备，聊天仍只读。结果须经平台回执确认，网络失败不自动重复写入。任务列表、报告与导出内容仍待提供。

2026-11-13：利用率类运行问题读取真实快照；各设备累计利用率与当前占用率分别计算、标注。今天 / 周 / 月等指定时间段缺少完整起止工作时长时明确说明不可准确统计，只提供累计 / 当前参考，不把现有按日处方计数功能冒称设备日利用率。

2026-11-13：锅号与煎药锅设备编号同义，聊天可列出真实锅号并按 `pot-49` 等原始设备编号精确查询，状态后追问锅号保留状态范围。未登记编号不猜测，不创建另一套锅编号；数据中心快捷入口定位同一设备编号。

2026-11-13：增加数据中心只读运行问答。常见锅 / 设备数量、使用、空闲、故障和报警问题优先读取已校验的仿真快照，明确实际数据时间与过期状态；不依赖药材资料或模型猜测。支持同设备主题的状态追问，并可打开对应数据中心筛选。不执行聊天修复、启停或其他平台写操作。

2026-11-01：页面移除「原文检索」开关，发送默认执行知识库检索 + AI 回答并展示原文。自动加载资料，失败提供重试；每轮保留引用与知识库追问上下文，不再提供页面普通 AI 模式。

提供真实登录、退出、个人改密和角色权限。管理员管理账号及资料，编辑员管理资料，普通用户查看与提问。SQLite 保存账号、会话和共享文本资料。所有登录用户共用中药基础资料库。

资料列表与原文通过真实服务读取；默认提供本地 Qwen3 + FAISS 向量检索，Markdown 数据位于 code/data；配置 DeepSeek 后优先根据后端检索到的原文作答并核对引用，相关资料不足时可补充模型一般知识，单独标为「AI 补充，非文档原文」且不挂文档引用；自然语言未命中时可先语义整理后重检，仍无原文时不生成回答；数字无意义输入不调用模型，不返回无关内容或引用；AI 支持当前会话最近 5 轮追问上下文；历史会话只在本页保留。PDF / Word 不伪造解析或上传成功。

新增独立中药饮片处方检查 Agent：登录用户可上传文件 / 图片或手动录入，LangGraph 编排读取、意图识别、提取、人工确认、有限规则检查和报告。处方不进入共享知识库，不持久保存；用户确认后才检查，提供基于有限规则的系统辅助审核结论：明确给出通过 / 不通过 / 待补充信息及判断依据。通过限定于本次系统覆盖项目，普通提醒与阻断项区分；不自动改方或伪造专业签署 / 临床放行。支持处方专用 PDF / Word 解析，共享知识库的通用解析仍在后续范围。

## 后续范围

通用 PDF / Word 上传解析、会话持久化、检索评测、流式回答、独立知识库授权、多租户与线上部署。

## 验收

未登录不能读取业务 API；普通用户不能调用写资料或管理账号接口；编辑员不能管理账号；管理员能完成账号生命周期操作。停用、角色和密码变化撤销旧登录。会话过期、错误密码、重复账号、空资料与超限有真实反馈。

桌面与手机核心操作可用、无横向溢出；资料刷新后保留；原文与回答来源一致；演示与真实能力明确区分。
