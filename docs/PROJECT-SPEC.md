# 项目定位与范围

更新：2026-10-27。

为整理中药资料并据此提问的用户提供知识库问答界面，帮助他们组织资料、阅读回答并回到原文核对引用。

## 已确认

- 左侧知识库和历史对话，中间问答及引用，右侧资料。
- 浅色、简洁、蓝色，沿用第 3 张设计，适配电脑和手机。
- 前端 Next.js 16、React 19、TypeScript。
- 后端采用 Python / FastAPI；提供登录界面，不同账号具有不同权限。

## 当前范围

提供真实登录、退出、个人改密和角色权限。管理员管理账号及资料，编辑员管理资料，普通用户查看与提问。SQLite 保存账号、会话和共享文本资料。所有登录用户共用中药基础资料库。

资料列表与原文通过真实服务读取；提供关键词原文检索，配置 DeepSeek 后优先根据后端检索到的原文作答并核对引用，相关资料不足时可补充模型一般知识，单独标为「AI 补充，非文档原文」且不挂文档引用；自然语言未命中时可先语义整理后重检，仍无原文时不生成回答；数字无意义输入不调用模型，不返回无关内容或引用；AI 支持当前会话最近 5 轮追问上下文；历史会话只在本页保留。PDF / Word 不伪造解析或上传成功。

## 后续范围

PDF / Word 解析、会话持久化、向量语义检索、流式回答、独立知识库授权、多租户与线上部署。

## 验收

未登录不能读取业务 API；普通用户不能调用写资料或管理账号接口；编辑员不能管理账号；管理员能完成账号生命周期操作。停用、角色和密码变化撤销旧登录。会话过期、错误密码、重复账号、空资料与超限有真实反馈。

桌面与手机核心操作可用、无横向溢出；资料刷新后保留；原文与回答来源一致；演示与真实能力明确区分。
