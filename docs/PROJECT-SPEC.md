# 项目定位与范围

更新：2026-10-26。

## 定位

为上传中药资料并据此提问的客户提供知识库问答界面，帮助他们组织资料、阅读回答并回到原文核对引用。

## 用户已确认

- 左侧：知识库和历史对话。
- 中间：问答内容，底部输入框。
- 回答：来源引用与原文片段。
- 上传：文档入口、上传和解析状态。
- 风格：简洁、浅色、蓝色，适配电脑和手机。
- 视觉：第 3 张方案。
- 工程：Next.js 16、React 19、TypeScript。

## 本轮交付范围

实现可运行的前端原型，包括知识库与会话切换、提问反馈、引用查看、复制、文件选择与拖拽、处理队列和移动抽屉。

文本资料在浏览器本地读取，问答返回原文摘录；预置资料使用有标识的演示内容。PDF / Word 只展示需要服务端解析的状态。

## 后续范围

服务器上传、PDF / Word 解析、持久化会话、向量检索、大模型与真实来源定位尚未实现。账号和独立组件分发也不在本轮范围。

## 验收

正常、空知识库、等待、处理、失败状态可辨认；核心操作可完成；桌面和手机无横向溢出；原文与回答来源一致；不把演示状态描述成真实后端结果。
