# 检索相关性修复验收

日期：2026-10-27。

## 问题与修复

用户输入「陈皮」和「111」都出现陈皮示例。根因有两处：示例资料存在时任意查询都会返回预设陈皮回答；真实文本的候选片段没有排除匹配分数为零的内容。此前接口验收未覆盖未命中相关性，不能据此断言回答正确。

当前提问只检索正式基础文档与真实共享文本。正式 Word 按章节聚合药材条目，中文问句分词后按关键词匹配；多关键词的普通检索需要全部匹配，命中已知药材名时定位对应条目。未找到时显示「未找到相关内容」，不产生回答片段或引用。首页不再预置示例对话与模拟文件，页面明确标识原文检索。

## 验证

- `frontend: pnpm typecheck`、`pnpm test`（12 项）、`pnpm build`：通过。
- 回归覆盖空知识库、未解析文件、示例排除、真实上传文本无匹配、正式文档的陈皮 / 完整问句、数字与通用栏目词、两个药材查询、显式概览、英文大小写及真实数字记录、正式文档和上传文本共存。
- 本机 Edge 桌面 1487 × 1058 与手机 390 × 844：空首页，检索「陈皮」引用正式 Word 对应条目；接着输入「111」「111有什么功效」无结果、无引用；新对话再次输入「111」结果一致。
- 引用可打开完整的结构化正式文档；资料加载失败时禁止提问，重新读取后可正常检索；无横向溢出和未处理页面异常。
- 本轮浏览器模拟登录和 API 传输，但使用实际导入的正式文档，真实执行前端检索。没有修改实际账号与资料数据库；后端未改动，未重复执行上轮已经通过的 16 项后端测试。

## 边界

当前为关键词匹配与原文摘录，尚不支持语义理解、自动推理或 AI 生成回答。通用 PDF / Word 上传解析与聊天持久化仍待接入。若此前页面已有预置示例，刷新页面后进入新的空对话。
