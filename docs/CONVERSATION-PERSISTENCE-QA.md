# 刷新保留历史会话验收

日期：2026-11-19。

## 实现

历史会话通过现有登录账号保存到后端 SQLite。首次进入和刷新读取摘要，再加载最近会话的完整消息；选择旧会话时按需读取，按当前会话最近五轮继续追问。保留问答正文、引用、工具调用、图表、已提供用量及实际回答时间；读取历史不会再次生成回答或执行已记录工具。

新增会话 / 消息表，账号与会话组合键隔离数据，消息 UUID 唯一且逐轮追加。同一内容重复保存不会重复计数，不同内容重放返回 409；多窗口保存不会整段覆盖另一窗口的消息。所有接口校验当前登录和 knowledge:read，写入沿用 CSRF，响应 no-store，单轮请求上限 8 MiB。启动时幂等建表，无新依赖和环境变量。

读取和保存有独立反馈及重试；保存失败保留当前页面回答并暂停新提问，重试只保存同一条消息，不调用模型。未保存时离开会提示。窄屏及导航收起时的提示区避开悬浮按钮。认证账号变化会重挂载工作区并取消旧提问，避免迟到回答保存到新账号。

## 已验证

- `pnpm typecheck` 和 `pnpm test` 通过，41 项前端回归；包含未加载正文的历史摘要按北京时间正确归日及显示轮数。
- `.venv\Scripts\python.exe -m unittest discover -s tests -v` 通过，251 项后端回归。新增 6 项验证未登录 / CSRF、跨账号隔离、完整引用与元信息往返、应用重启保留、幂等 / 冲突、并发追加、时间 / 输入校验及超限请求不落库。
- 隔离 Chrome 在 1440×900、390×900 使用真实临时 SQLite 与临时登录账号完成刷新恢复、恢复后追问、切换旧会话、新会话空上下文、引用打开、保存失败后同 ID 重试、历史读取失败恢复、重新登录、跨账号读取隔离及账号变化取消旧回答验证。刷新和重试均不新增模型请求，页面无异常，无横向溢出。
- 已查看桌面和手机历史窗口截图。临时脚本、数据库、截图与结果保存在被忽略的 `tmp/conversation-persistence-qa/`；模型回答与知识资料为明确的模拟内容，历史保存和账号校验使用真实接口，未写入真实仿真平台。

## 运行更新与边界

最终源码在隔离副本执行 `pnpm build --webpack` 通过，仅副本设置单 worker；首次被项目现有 Next.js 16.4.3 安全升级提醒中断，按提示重试通过，依赖升级继续保留为待办，未修改项目依赖。

已先通过 SQLite backup 接口将当前数据库备份到被忽略的 `backend/data/backups/`，再隐藏重启本机后端。旧启动器占用原日志导致首个启动进程退出，改用独立日志后启动正常；本地 Qwen / FAISS 预热完成。最终确认后端 8000、前端 3000 和同源 API 代理健康，OpenAPI 中历史列表与消息追加接口均已加载。本机账号、登录会话、共享资料及既有业务数据保留。

仅保存已完成并成功提交保存的问答，不保存未发送草稿或正在生成中的回答。保存失败时需保留当前页面并重试；用户强制离开后，未写入数据库的回答无法恢复。改动上线前已刷新清空的旧记录无法补回。独立知识库和多租户授权不在本次范围内。
