# 运行总览侧栏快捷入口验收

日期：2026-11-16。

按用户截图，在侧栏「数据中心」正下方增加同级「运行总览」。点击复用现有数据中心弹窗，直接选中第四个标签；原数据中心仍默认打开概览，四个标签共用数据快照和顶部刷新。

## 验证结果

- `frontend` 中 `pnpm typecheck` 和 `pnpm test` 通过，现有 33 项回归全部通过。
- `tmp/operations-shortcut-build-*` 隔离副本运行 `pnpm build` 通过；使用已有依赖、单构建工作进程，未覆盖日常开发服务。
- 开发服务和隔离生产构建均通过 1440 / 390 / 320px 浏览器核验：前三项导航顺序正确，没有额外运行分组；Enter 激活快捷入口直接打开现有总览、九项指标和14类设备，只有一个弹窗。
- 原数据中心入口仍默认打开概览，原设备和处方标签可用；鼠标和方向键切换标签同步侧栏高亮，没有新增独立快照请求，顶部刷新更新同一总览。
- Escape 关闭后桌面焦点回到快捷入口，手机回到导航按钮；问答草稿保留，AI Agent 恢复选中。手机打开快捷入口自动收起导航。
- 页面、弹窗及总览内容没有整体横向溢出，无页面脚本错误；桌面导航、手机导航与窄屏总览截图已查看。临时生产服务已关闭。
