# 资料优先与 AI 补充验收

日期：2026-10-27。用户选择「资料优先；允许补充模型知识，并明确标注为 AI 补充、非文档原文」。此前仅依据原文的回答策略已调整。

## 行为

- 先检索知识库；有相关资料但内容未覆盖所问时，允许模型一般知识单独补充。完全无相关片段仍返回未找到，不调用模型；不提供通用闲聊。
- 文档段 origin=document，需要至少一个有效文档编号。补充段 origin=ai_supplement，citations 必须为空，前端显示「AI 补充，非文档原文」，不挂文档引用。
- 复制保留文档 / 补充类别。只返回实际被引用的文档；补充段省略 sourceIndex，sourceIndices=[]。
- 功效等明确字段问题聚焦相应原文并保留注意事项；全文仍可打开。饮片 / 炮制问题补检相关总论，避免只找到药材功效条目后答非所问。
- 补充来自模型自身知识，没有联网检索或核实。提示词要求避免把未核实的精确加工参数写成规范。来源类别由模型申报，服务端校验字段与引用关系，不保证逐句事实、出处归类或医学准确性。

## 验证

后端 35 项测试通过，覆盖原有鉴权 / 资料 / 账号行为，以及混合来源、补充不可挂引用、资料不可缺引用、纯补充不带闲置来源、加工章节召回、功效 / 剂量字段边界。前端 pnpm typecheck 与 pnpm test（12 项）通过。

当前前端已在隔离源码副本完成 next build --webpack 生产构建。后续仅调整后端提示词时复用同一前端构建，经 3107 端口的真实 Next.js 代理请求 8107 FastAPI；使用临时 SQLite、随机测试密码、真实 DeepSeek，无 API 模拟，不创建实际业务账号。

11 项浏览器检查通过，未处理页面异常为 0；桌面 1487 × 1058、手机 390 × 844 的截图已人工查看，无横向溢出。

| 真实提问 | 本次结果 |
| --- | --- |
| 黄芪做药饮片一般怎么处理 | 1 段文档依据，引用炮制相关原文；1 段 AI 通用加工补充，清晰标注且无文档引用 |
| 陈皮有什么功效 | 3 段原文支持的功效 / 应用 / 注意信息，不展开未问到的剂量；本次无需 AI 补充 |
| 陈皮和青皮有什么区别 | 按共同点和差异比较，保留两个真实条目的引用 |
| 111 | 未找到相关内容，正文 / 文档 / 补充均为空 |

另已验证复制保留类别、文档引用打开完整原文、手机补充标签和布局。模型输出有随机性，段落数不是接口保证；测试重点是内容聚焦与来源类别 / 引用边界。
