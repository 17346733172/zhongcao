## 知识库桌面

当前视觉参考为用户提供的 DeepSeek 截图：浅灰可收起侧栏与白色聊天区两栏；标题 / 正文统一无衬线。空会话欢迎语与输入框居中，发问后输入框位于底部，问题靠右显示。

左栏：品牌、中药基础资料、数据中心、测试（测试执行、测试方案）、智能（AI Agent、Token 统计）、设备与系统（设备配置、系统设置），底部保留当前用户、角色、个人账号、账号管理入口（仅管理员）及退出。「中药基础资料」只打开文档阅读弹窗，支持章节定位和 Word 下载；测试执行显示布局预览，其余五个待接入入口显示内容待补充弹窗。运行总览位于数据中心第四个标签。

中间：知识库标题、固定「原文 + AI」标识、回答与引用、输入框；右上角不再显示资料入口。发送默认原文检索 + AI 回答，未配置时明确提示，失败保留草稿；生成回答直接显示标题和正文，不显示模型名和重复生成说明；原文摘录与其他状态保留提示。生成段落进一步区分「资料依据」和「AI 补充，非文档原文」；补充段使用单独边框和标签、不显示文档引用，复制后也保留来源类别。当前会话可承接省略主题的 AI 追问，如陈皮后问「作用？」；新建对话不带旧上下文，缺主题或指代不明显示补充问题提示。首页为空对话；查询未命中显示「未找到相关内容」，不展示片段或引用。共享资料读取有加载与错误重试。

共享资料上传 / 管理抽屉已移除，既有保存资料继续用于知识库问答，后端 API 和权限保留。输入框旁「处方检查」直接进入处方专用上传、核对与检查流程。

## 处方检查弹窗

输入框旁「处方检查」直接打开独立弹窗，保留聊天草稿；基础资料弹窗不再提供处方标签。上传页提供文件 / 图片选择、拖入、文字粘贴和手动录入；核对页展示原始图片、识别原文、基本信息与可编辑药物表格，确认后才能检查；报告区分数据异常、用药疑点、信息缺失与人工复核，支持依据链接、复制和修改后重查。每份新处方清除旧数据；关闭弹窗取消浏览器等待并释放图片预览地址。桌面和手机共用流程，药物表格仅在自身容器横向滚动，Tab 约束在弹窗内、Escape 关闭。

## 登录与管理

登录采用品牌说明和表单两栏，手机简化品牌区域。账号和密码有标签、自动填充、密码显隐与忙碌 / 错误状态。无自助注册和未实现的找回密码按钮。

管理页面使用创建表单与成员列表两栏，手机上下排列。角色和停用真实保存，密码表单不保留成功提交后的密码。管理员不能停用或修改自己的角色。

## 知识库状态与移动

页面固定使用「原文 + AI」，不显示原文检索开关。资料自动读取，点击发送或按 Enter 均提交知识库问答并附加同次检索原文。页脚显示「基于知识库原文生成回答，请核对引用资料」。加载 / 错误 / 重试、复制、原文查看与手机导航沿用既有组件。

每轮显示真实引用，追问保留最近五轮知识库摘要；新建对话清空上下文但继续使用原文 + AI。AI 生成正文隐藏总标题，原文、问候、澄清和未命中保留标题。两边均未命中时仅显示一条提示，失败保留草稿。

回答排版按最新 DeepSeek 截图采用 16px 正文、1.75 行高、800px 最大阅读宽度与加粗分节标题，来源小标签放在标题旁。生成正文可展示 Markdown 段落、加粗、列表、引用、代码与表格；原文仍按原字面文本显示。手机正文保持 16px，长表格在自身区域内滚动，复制保留 Markdown 结构与来源标识。

AI 回答和原文结果下方都不显示「引用资料」卡片；两个区域的正文引用编号均直接打开对应原文弹窗，原文摘录与复制继续保留。

提供空对话、新对话、真实模型生成等待、检索命中 / 未命中、原文弹窗与处理失败状态。生成失败保留草稿，新建 / 切换会话取消旧请求。手机导航通过顶部按钮打开；所有角色可通过输入框「处方检查」打开独立检查弹窗，Escape 关闭并恢复入口焦点。原文弹层与检查弹窗分别管理键盘焦点。

不创建官网、组件详情页或独立组件 Registry。

处方上传与核对页均展示本方剂量口径，默认每一剂的量，可切换总量或逐味设置；新增行继承整方选择。结果显示实际检查口径。保留在浏览器内的旧格式报告会按用户已确认的每剂量自动重查并更新成功后的快照。
