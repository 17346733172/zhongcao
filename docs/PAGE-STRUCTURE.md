# 本草知问页面结构

## 路由

| 路由 | 用途 | 访问条件 |
| --- | --- | --- |
| /login | 账号密码登录、错误反馈、密码显隐 | 公开，已有登录则回知识库 |
| / | 知识库、当前页会话、AI / 原文回答与共享资料 | 已登录 |
| /account | 角色、权限说明与修改自己的密码 | 已登录 |
| /admin | 创建账号、角色、停用 / 启用、重置密码 | 管理员 |

页面通过会话检查后展示内容；业务数据访问和权限由后端独立校验。非管理员直接进入 /admin 会返回知识库。服务不可用时提供重试，登录失效时返回 /login。

## 知识库桌面

当前视觉参考为用户提供的 DeepSeek 截图：浅灰可收起侧栏与白色聊天区两栏；标题 / 正文统一无衬线。空会话欢迎语与输入框居中，发问后输入框位于底部，问题靠右显示。

左栏：品牌、新建对话、知识库、历史对话、当前用户、角色、个人账号、账号管理入口（仅管理员）、退出。「中药基础资料」点击后打开《中药基础知识（详解版）》阅读弹窗，保留对话与输入；正文按原文章节和表格展示，支持章节定位、Word 原文件下载、加载与失败重试。

中间：知识库标题、AI 问答 / AI + 原文标识、资料入口、回答与引用、输入框和附加原文开关。发送默认 AI 回答，未配置时明确提示，失败保留草稿；生成回答直接显示标题和正文，不显示模型名和重复生成说明；原文摘录与其他状态保留提示。生成段落进一步区分「资料依据」和「AI 补充，非文档原文」；补充段使用单独边框和标签、不显示文档引用，复制后也保留来源类别。当前会话可承接省略主题的 AI 追问，如陈皮后问「作用？」；新建对话不带旧上下文，缺主题或指代不明显示补充问题提示。首页为空对话；查询未命中显示「未找到相关内容」，不展示片段或引用。共享资料读取有加载与错误重试。

右侧资料抽屉（默认关闭）：管理员 / 编辑员看到文本添加、处理结果与移除；普通用户看到只读说明和原文列表。所有角色可刷新共享资料。持久化文本标为「已保存 · 共享」，预置资料标为「示例」，PDF / Word 标为「未上传 · 待接入解析服务」。

## 处方检查弹窗

侧栏「处方检查」打开独立弹窗，保留聊天草稿；右侧资料抽屉不再重复提供此入口。上传页提供文件 / 图片选择、拖入、文字粘贴和手动录入；核对页展示原始图片、识别原文、基本信息与可编辑药物表格，确认后才能检查；报告区分数据异常、用药疑点、信息缺失与人工复核，支持依据链接、复制和修改后重查。每份新处方清除旧数据；关闭弹窗取消浏览器等待并释放图片预览地址。桌面和手机共用流程，药物表格仅在自身容器横向滚动，Tab 约束在弹窗内、Escape 关闭。

## 登录与管理

登录采用品牌说明和表单两栏，手机简化品牌区域。账号和密码有标签、自动填充、密码显隐与忙碌 / 错误状态。无自助注册和未实现的找回密码按钮。

管理页面使用创建表单与成员列表两栏，手机上下排列。角色和停用真实保存，密码表单不保留成功提交后的密码。管理员不能停用或修改自己的角色。

## 知识库状态与移动

默认未勾选「原文检索」时为普通 AI 问答，后端不使用知识库，前端不自动加载资料；页脚显示「内容由 AI 生成，未使用知识库」。勾选后才加载资料并使用知识库问答与附加原文。两种模式各自保留最近五轮追问历史；资料读取失败不阻止取消勾选后继续普通 AI 提问。主动打开资料抽屉或基础文档仍可阅读资料。

输入框移除「AI 回答」按钮，点击发送或按 Enter 默认 AI 回答。「原文检索」默认关闭，可开启 / 取消；开启时同一轮先展示 AI 回答、再展示原文检索结果，各自支持复制和引用，关闭后仍使用 AI 回答。需要澄清时先显示澄清提示；生成中禁止切换选项。手机保留同样的行为，服务状态返回不覆盖原文开关。

开启原文检索后仅展示有内容的结果：AI 未命中但原文命中时只显示原文，原文未命中但 AI 有内容时只显示 AI；两边都未命中时只保留一条提示，两边都有内容时分别展示。当前页已有会话同步采用此规则，原始响应与追问上下文保留，复制和引用跟随可见结果。

每轮记录发送时是否开启「原文检索」：未开启时不显示正文引用编号和「引用资料」区域，开启后才显示 AI 与原文结果各自的引用。切换开关和历史会话不改变旧回答的展示选择。

勾选模式的 AI 生成回答省略总标题，复制同步；正文分节、引用与独立原文结果标题保留。普通 AI 和澄清 / 未命中 / 问候仍显示各自标题。

回答排版按最新 DeepSeek 截图采用 16px 正文、1.75 行高、800px 最大阅读宽度与加粗分节标题，来源小标签放在标题旁。生成正文可展示 Markdown 段落、加粗、列表、引用、代码与表格；原文仍按原字面文本显示。手机正文保持 16px，长表格在自身区域内滚动，复制保留 Markdown 结构与来源标识。

AI 回答下方不再重复显示「引用资料」卡片，仅下方原文结果保留该卡片；AI 正文编号直接打开对应原文弹窗，原文结果编号仍切换自己的资料卡片。

提供空对话、新对话、真实模型生成等待、检索命中 / 未命中、原文弹窗与处理失败状态。生成失败保留草稿，新建 / 切换会话取消旧请求。手机导航和资料分别通过顶部按钮打开抽屉，Escape 关闭，原文弹层与抽屉管理键盘焦点。所有角色的右上角入口和抽屉标题统一为「知识库资料」，按原权限显示共享资料的上传 / 查看 / 移除操作。

不创建官网、组件详情页或独立组件 Registry。

处方上传与核对页均展示本方剂量口径，默认每一剂的量，可切换总量或逐味设置；新增行继承整方选择。结果显示实际检查口径。保留在浏览器内的旧格式报告会按用户已确认的每剂量自动重查并更新成功后的快照。

处方检查结果仅显示复制按钮与 3.1—3.5 五节审核正文，采用加粗结论、项目符号和编号建议；去掉计数、彩色问题卡片、明细折叠、版本及范围面板。页面与复制使用同一 sections 数据，修改复查更新全部正文；信息缺失仍在对应核查段落说明。

3.1 下直接列本次需补充信息，包含患者字段与具体药物行的缺失字段；「去补充信息」返回核对页并聚焦首项，现有值不清空、原确认勾选失效。补齐后报告移除对应提示；五节正文及复制保持一致，不恢复旧问题卡片。

3.1 由系统直接给出「通过 / 不通过 / 待补充信息」，下方附具体判断依据。通过在同段限定为本次系统已覆盖检查通过，真实缺失提示继续保留，普通用药提醒留在核查正文。旧报告缺少新判断依据字段时自动重查。
