# 本草知问页面结构

当前仅有根路由 /，不增加官网、登录或管理后台页面。

## 桌面

左栏展示品牌、新建对话、知识库、历史对话和本次会话说明。

中间展示当前知识库标题、演示标识、上传入口、问答内容、引用原文、输入框和运行模式说明。

右栏展示文件选择与拖拽区域、文件队列、进度、处理结果和本地文件说明，可关闭后从顶部重新打开。

## 状态

- 默认：陈皮资料演示会话，展开第一个引用。
- 新会话：展示开始提示和示例问题。
- 空知识库：提示添加资料。
- 提问中：输入暂时禁用，显示处理反馈。
- 原文：从文件名进入模态查看，支持关闭和 Escape。
- 上传：排队、读取、就绪、需要解析服务、错误。

## 移动

导航和上传分别通过顶部按钮打开抽屉。主内容独立滚动，输入区保持可用；完整原文使用适合手机宽度的弹层。

不创建组件详情页，Registry 暂不启用。
