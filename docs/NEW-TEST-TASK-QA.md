# 新建测试任务入口验收

日期：2026-11-14。

后续按用户反馈重新分组操作栏，并将累计运行时间替换为每秒更新的当前北京时间，见[排版与实时钟验收](NEW-TEST-TASK-LAYOUT-QA.md)。以下记录为最初弹出界面交付时的验证。

按用户新图，点击测试执行页的「新建测试任务」后打开「全局仿真控制」上层弹窗。本轮完成弹出界面、数量输入及只读状态显示；生成演示数据、开始和暂停仍明确待接入，没有新增平台控制接口。

## 已交付

弹窗包含默认5的批次数量、1–50整数校验、生成演示数据、开始、暂停、累计运行时间、真实计时说明和状态提示。累计时间与状态读取既有快照，不复制截图值；未读取时显示等待或失败提示，可重新读取。未接入的控制按钮禁用并解释原因。

上下两层dialog为兄弟节点，由原生模态机制隔离焦点。Escape或关闭按钮只关闭上层，焦点返回新建按钮；测试执行仍保持原标签，问答草稿保留。关闭后取消上层轮询与页面等待。

## 验证

- `frontend` 中 `pnpm typecheck`、`pnpm test` 的33项回归通过。
- 初次并行检查遇到系统资源不足；改为逐项执行，并限制临时Node堆、Rust线程和构建页生成并发。最终源码隔离副本 `pnpm build` 通过，含TypeScript及六个静态页面生成。仅临时副本设置`experimental.cpus=1`，正式配置未改。
- 最终生产版本3218端口，1591×900、1440×900、390×1000、320×1000、deviceScaleFactor=1，四种尺寸均通过，页面 / 弹窗无整体横向溢出。
- 新建按钮可用；打开后默认5，0、51、1.5、空值均提示错误，50有效。生成 / 开始 / 暂停均禁用。
- 运行中、已暂停、读取失败和重试恢复使用隔离接口响应验证；累计时间无数据时为「—」。接口方法记录只有GET，没有生成、开始、暂停或其他写请求。
- 双层Escape、关闭按钮、Tab / Shift+Tab约束、返回新建按钮、保留历史批次标签和外部草稿均通过；无浏览器运行错误。
- 桌面、手机截图已查看，完成首轮字号修正后的最终同图复核，见根目录[视觉验收](../design-qa.md)。临时生产服务已关闭，日常3000端口开发服务保留。
