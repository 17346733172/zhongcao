# 处方检查快捷入口验收

日期：2026-11-16。

本记录为输入框入口迁移时的验收。之后资料弹窗已移除处方标签、改名「中药基础资料」，最新验证见 [基础资料拆分验收](REFERENCE-ONLY-QA.md)。

输入框旁的回形针已替换为「处方检查」图标加文字按钮，所有登录角色均可直接打开现有独立处方弹窗。原共享资料上传 / 管理面板、前端上传与移除逻辑及专用样式已删除。左侧「中药资料与处方」、既有知识库数据和后端资料 API 保留。

## 验证结果

- `frontend` 目录运行 `pnpm typecheck`、`pnpm test`：通过，33 项现有回归全部通过。
- 在 `tmp/prescription-entry-build-*` 源码副本运行 `pnpm build`：通过。仅为隔离构建配置 Turbopack 项目根目录及单工作进程，未修改应用运行配置或覆盖开发服务。
- 使用现有 Playwright / Chrome，在开发服务与独立生产预览分别验证普通用户、编辑员、管理员和 1440 / 390 / 320px，共九种组合；无页面脚本错误或整体横向溢出。
- 三种角色均能直接打开处方检查，没有基础资料标签或共享资料上传内容；文件 / 图片按钮指向处方专用选择框，选中文本文件后可移除。左侧工具及其处方标签仍可用。
- 普通用户在三种宽度下完成手动录入、勾选人工确认、模拟检查失败、保留输入重试、展示五节模拟报告、返回修改。检查请求保留每剂量口径和「3 片」，并携带 CSRF 请求头。
- Escape 和关闭按钮退出弹窗，焦点返回「处方检查」，聊天草稿保留；再次打开清空上一份处方。320px 模拟共享资料读取失败，新入口仍可使用。
- `node --check frontend/scripts/check-auth-browser.mjs` 与 `node --check frontend/scripts/check-answer-mode.mjs` 通过。鉴权浏览器脚本已改为直接验证保留的资料 API，移除旧抽屉操作依赖。
