日期：2026-11-16。

将现有问答主页接入侧栏「智能 → AI Agent」，默认选中该项，点击直接展示问答主区。保留顶部资料标题、原文 + AI 标识、欢迎语、输入框、处方检查及状态提示，不再打开 AI Agent 占位弹窗。

## 验证结果

- `frontend` 目录运行 `pnpm typecheck`、`pnpm test`：通过，现有 33 项回归全部通过。
- `tmp/ai-agent-build-*` 隔离副本运行 `pnpm build`：通过。复用已有依赖，仅在副本配置 Turbopack 根目录和单构建工作进程，未覆盖正在运行的开发服务。
- 开发服务与隔离生产构建均通过三种角色、1440 / 390 / 320px 共九种浏览器场景；默认选中 AI Agent，使用当前页面语义，没有弹窗属性，主区可操作。
- 鼠标及 Enter 激活 AI Agent 后保持草稿与对话；手机自动收起导航。重复点击不重新请求资料，不生成占位弹窗。
- 问候、本次知识问答请求、模拟发送失败保留问题、重试及正文引用原文均正常；资料加载失败也可使用 AI Agent。
- 中药基础资料、数据中心、测试执行、Token 统计及独立处方检查入口仍可打开；关闭后回到问答主区，对话及草稿保留，侧栏恢复 AI Agent 选中态。
- 无页面脚本错误或整体横向溢出；桌面与手机截图已核对。临时生产预览已停止。
