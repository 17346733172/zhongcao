# 常见中药材操作手册

> 适用范围：中药房调剂、诊所代煎、教学实训，以及在医师指导下进行的家庭煎服。  
> 内容依据：项目内置《中药基础知识（详解版）》、现行《中国药典》及常规炮制与煎药规范整理。  
> 版本：v1.0 · 2026-10-27

## 使用说明与安全声明

1. 本手册讲“怎么操作”，不替代诊断与处方。内服药材应在执业中医师或药师指导下使用，处方药与毒性药材不得自行购买服用。
2. 文中剂量均为**成人一日常用量**，取自内置教材；儿童、老人、体弱者、孕妇、哺乳期妇女及肝肾功能不全者须由医师调整。
3. 涉及毒性药材（附子、川乌、草乌、半夏、天南星、甘遂、巴豆、朱砂、雄黄等）的操作，必须使用合规炮制品，遵守《医疗用毒性药品管理办法》，不得自行炮制、加量或延长疗程。
4. 出现口舌麻木、心悸、皮疹、呼吸困难、剧烈腹泻等不良反应，应立即停药并就医，同时保留药渣、药液和包装供追溯。
5. 本手册中的感官鉴别与储存建议属于一般操作参考，不能替代《中国药典》标准、供应商质检报告和执业药师审核。

## 一、验收与入库

### 1.1 到货核对

- 核对品名、炮制规格、产地、批号、生产日期或有效期、供应商资质与质检报告。
- **炮制规格必须与处方一致**：处方写“炙黄芪”不能发“生黄芪”，写“法半夏”不能发“生半夏”，写“附子”须确认具体炮制品种。
- 毒性药材单独交接、双人复核、专柜加锁、专账记录。
- 称量使用分度值不大于 0.1 g 的电子秤；毒性药材逐味复核并记录；一剂总重与分帖误差应可追溯。
- 包装破损、受潮、无标签或标签信息不全的，拒收并留样。

### 1.2 感官检查

| 异常现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 霉斑、白毛、绿毛、酸霉味 | 受潮霉变 | 整批隔离，不得晾晒或清洗后继续使用 |
| 虫蛀、虫卵、蛀粉 | 仓储害虫 | 隔离；能否继续药用由药师判定，不得自行筛除后使用 |
| 泛油、走油、哈喇味（当归、桃仁、柏子仁、枸杞子） | 油脂氧化 | 不得再供内服 |
| 泛糖、发黏（熟地黄、麦冬、天冬） | 吸潮 | 隔离评估，不得自行烘干后使用 |
| 花类变色、褪色 | 光照、氧化 | 降级或报废 |
| 异常酸味、刺鼻味、农药味 | 变质或污染 | 拒收并留样 |
| 包装胀袋、渗液、封口破损 | 运输或仓储污染 | 拒收 |

感官检查只能作为初筛。涉及真伪、含量、农残、重金属和二氧化硫等项目，以供应商质检报告和法定检验为准。

### 1.3 易混淆药材

| 易混淆 | 关键区别 | 操作提示 |
| --- | --- | --- |
| 川贝母 / 浙贝母 | 川贝颗粒小、质坚实，松贝可见“怀中抱月”；浙贝较大、苦味明显 | 价格差异大，按处方规格核对，不得互相替代 |
| 三七 / 土三七（菊三七） | 三七为五加科，断面灰绿或黄绿；土三七含吡咯里西啶生物碱，可致肝损伤 | 严禁混用；购买“三七”须核对来源与拉丁名 |
| 金银花 / 山银花 | 药典分列，来源、成分与价格不同 | 按标签和质检报告核对，不凭外观互换 |
| 附子 / 川乌 / 草乌 | 均为乌头类，毒性强，炮制规格不同 | 专柜管理，不得凭外观自行判断或替代 |
| 生半夏 / 法半夏 / 姜半夏 / 清半夏 | 炮制规格不同，功效与毒性差异大 | 处方写哪种发哪种；生品不得内服 |

## 二、炮制与临方处理

### 2.1 炮制的目的

炮制直接关系药效与安全，主要目的包括：

1. **降低或消除毒性、副作用**：如附子、川乌、草乌经炮制后毒性大减；生半夏、生天南星有毒，制后可供内服。
2. **改变或缓和药性**：生地黄清热凉血，熟地黄滋阴补血；生姜发散风寒，干姜温中回阳，炮姜温经止血。
3. **增强疗效**：蜜炙黄芪增强补气，醋炙延胡索增强止痛，酒炙川芎增强活血行气。
4. **改变作用部位与趋向**：酒制上行头目，盐制下行入肾，醋制入肝。
5. **便于调剂、制剂、贮藏和服用**：切制成饮片便于称量与煎煮，干燥和炮制可防霉防虫，矫味矫臭便于服用。

### 2.2 常用炮制方法

| 类别 | 常用方法 | 示例 |
| --- | --- | --- |
| 修治 | 纯净、粉碎、切制 | 去芦、去皮心，切段、切片 |
| 水制 | 漂洗、浸泡、润、水飞 | 水飞朱砂、炉甘石 |
| 火制 | 炒（清炒、加辅料炒）、炙、煅、煨、烘焙 | 清炒王不留行、蜜炙黄芪、煅牡蛎、面裹煨肉豆蔻 |
| 水火共制 | 煮、蒸、燀、淬 | 煮川乌、蒸熟地黄、燀杏仁、煅淬自然铜 |
| 其他 | 制霜、发酵、发芽 | 巴豆霜、神曲、麦芽 |

辅料不同，作用不同：蜜炙补脾益气、润肺止咳；酒炙活血通络、引药上行；醋炙入肝止痛、增强收敛；盐炙引药下行、入肾；姜炙温中止呕、降低毒性。

### 2.3 临方处理

- **净制**：挑拣杂质，去除非药用部位。薄荷、砂仁、藿香等芳香类药材不宜长时间水洗，快速过水后沥干即可。
- **洗润**：冷水快洗，避免有效成分流失；润至内外湿度一致再切制，防止碎裂。
- **切制**：按煎煮需要切成片、段或块。家庭场景一般直接使用合格饮片，不建议自行切制坚硬根茎。
- **干燥**：阴干或低温干燥，一般不超过 60 ℃；芳香类药材避免高温，以免挥发油损失。
- **打碎**：果实种子类（酸枣仁、桃仁、砂仁、栀子）临煎打碎；矿物贝壳类（石膏、牡蛎、石决明）打碎后先煎。

### 2.4 毒性药材的操作要求

- 必须使用药典规定的炮制品：附子（黑顺片、白附片等）、半夏（法半夏、姜半夏、清半夏）、天南星（制）、川乌与草乌（制）、马钱子（制）、巴豆（巴豆霜）。
- 生品不得内服，不得自行浸泡、蒸煮“去毒”；加工产生的废水、药渣按有毒废物处理。
- 朱砂、雄黄**不入煎剂**：朱砂入丸散或冲服，雄黄入丸散，且忌火煅（传统有“雄黄见火毒如砒”之说）。
- 毒性药材的领用、称量、煎煮、发放应双人复核并留存记录。

### 2.5 家庭与代煎场景的边界

家庭只处理常规饮片；毒性药材、动物药、胶类及特殊煎法药材交由药房处理。代煎机构应具备相应资质，做到一方一煎、留样、批记录，药袋标明姓名、日期、剂数和煎法。

## 三、煎药操作

### 3.1 器具与用水

- 首选砂锅、瓦罐、陶瓷锅；玻璃锅和合格不锈钢锅可用。
- **忌用铁器、铝器、铜器**，以免与鞣质、有机酸等成分发生反应，影响药效或产生异味。
- 每次使用后清洗干净，不残留油污和洗涤剂，不与烹调食物混用。
- 使用洁净饮用水；加水量以漫过药面 2～3 cm 为宜。

### 3.2 标准流程

1. 核对处方、姓名、剂数与特殊煎法，将先煎、后下、包煎、另煎、烊化、冲服药材单独分装。
2. 冷水浸泡约 30 分钟；花叶类可缩短至 20 分钟，根茎、矿物类可延长至 30～60 分钟。
3. **头煎**：武火煮沸后转文火保持微沸，按药类煎煮 10～40 分钟（见 3.3），期间搅拌 1～2 次，避免糊底。
4. 滤出头煎药液；药渣加温水至漫过药面 1～2 cm，**二煎**文火煎 8～30 分钟。
5. 合并两次药液，总量一般约 400～500 mL，分 2～3 次温服；具体以医嘱为准。
6. 特殊煎法药材按 3.4 处理。
7. 记录煎药时间、药液量、特殊情况和操作人。

### 3.3 煎煮时间参考

| 药类 | 头煎 | 二煎 | 要点 |
| --- | --- | --- | --- |
| 解表药、芳香药 | 10～15 分钟 | 8～10 分钟 | 武火急煎；后下药在结束前 5～10 分钟放入 |
| 一般药 | 20～30 分钟 | 15～20 分钟 | 文火保持微沸 |
| 补益药 | 30～40 分钟 | 20～30 分钟 | 文火久煎，使有效成分充分溶出 |
| 矿物、贝壳类 | 先煎 20～30 分钟后下其他药 | 20～30 分钟 | 打碎后先煎 |
| 毒性药（附子、川乌、草乌） | 先煎 30～60 分钟，至口尝无麻辣感 | 20～30 分钟 | 必须专人复核，不得缩短先煎时间 |

### 3.4 特殊煎法

| 煎法 | 适用药物 | 说明 |
| --- | --- | --- |
| 先煎 | 矿物、贝壳类（石决明、牡蛎、龙骨、磁石）；毒性药（附子、川乌、草乌） | 矿物贝壳先煎 20～30 分钟；毒性药先煎 30～60 分钟，至口尝无麻辣感 |
| 后下 | 气味芳香药（薄荷、砂仁、白豆蔻）；久煎易破坏有效成分者（大黄、钩藤、番泻叶） | 在其他药将煎好前 5～10 分钟放入 |
| 包煎 | 黏液质多、有绒毛、细小粉末及易使药液浑浊者（车前子、旋覆花、蒲黄、滑石、辛夷） | 用纱布袋包好后再煎 |
| 另煎 | 贵重药（人参、西洋参、鹿茸） | 单独煎煮，药液兑入其他药液中服 |
| 烊化 | 胶类药（阿胶、鹿角胶、龟甲胶） | 用开水或黄酒溶化，或兑入煎好的药液中 |
| 冲服 | 粉末、汁液及贵重细料（三七粉、羚羊角粉、琥珀粉、芒硝） | 研末或取汁，用药液或温开水冲服 |
| 煎汤代水 | 灶心土等 | 先煎取上清液，再以其代水煎其他药 |

### 3.5 煎药机与代煎

- 按设备说明设定温度、压力和时间；解表药、芳香药不宜高压久煎。
- 一剂一袋，标明姓名、日期、剂数、煎法和保存条件。
- 代煎药液冷藏保存并尽快服用，发放时交代加热方法和异常识别。

### 3.6 常见问题处理

| 问题 | 处理 |
| --- | --- |
| 煎糊、有焦味 | 有效成分已破坏，并可能产生有害物质；整锅弃掉，不加水续煎，不服用 |
| 煎干但未糊 | 药效已受损；弃用或由医师决定，不自行加水后继续煎 |
| 药液浑浊、大量沉淀 | 用纱布过滤；若为包煎袋破裂，记录并告知医师，必要时补足 |
| 药液表面有油滴或异味 | 可能为药材泛油或变质；停止服用并核查药材 |
| 煎药锅难清洗 | 温水浸泡后清洗，不用钢丝球刮擦 |
| 药液保存 | 当日煎当日服为佳；冷藏不超过 24 小时，服用前充分加热；出现浑浊、酸味、气泡或胀袋立即丢弃 |

## 四、服用与监护

### 4.1 剂量

- 成人一日常用量：一般药物 3～10 g；质轻的花叶类 3～6 g；质重的矿物、贝壳类 15～30 g。
- 毒性药材严格按药典和处方执行，如附子 3～15 g、细辛 1～3 g、吴茱萸 2～5 g，不得自行加量。
- 儿童按年龄、体重折算，一般为成人量的 1/3～1/2，新生儿更少；老人从低剂量开始。均须医师决定。
- 不把“一剂”当作“一次”，不自行拆分或合并剂量。

### 4.2 服药时间

| 药类 | 建议时间 |
| --- | --- |
| 补益药 | 饭前 30～60 分钟 |
| 对胃肠有刺激的药物 | 饭后 30～60 分钟 |
| 驱虫药 | 空腹 |
| 安神药 | 睡前 30～60 分钟 |
| 解表药 | 不拘时，趁热服，服后避风 |
| 急性病用药 | 不拘时，可频服 |

具体服药时间以医嘱为准；需要同时服用中西药时，一般间隔 1～2 小时。

### 4.3 服药温度

- 一般宜温服。
- 解表药宜热服，服后加盖衣被以助发汗。
- 寒证用热药宜热服；热证用寒药可温服或凉服。
- 真热假寒证用寒药宜热服，真寒假热证用热药宜凉服（反佐服法）。

### 4.4 疗程与复诊

- 一般方剂 3～7 剂后复诊，由医师根据反应调整。
- 慢性病可 2～4 周评估一次，不长期自行续服。
- 毒性药材“中病即止”，不得以“巩固疗效”为由延长疗程。

### 4.5 中西药联用

- 中药与西药一般间隔 1～2 小时服用。
- 含金属离子的中药（石膏、牡蛎、石决明）与四环素类、喹诺酮类抗生素间隔 2 小时以上。
- 丹参、当归、红花、川芎等活血药与华法林、抗血小板药合用可能增加出血风险，须告知医师并监测。
- 甘草长期大量使用与利尿剂、糖皮质激素、地高辛合用存在风险，不宜自行长期服用。

### 4.6 不良反应识别与处置

| 表现 | 可能相关药物 | 处置 |
| --- | --- | --- |
| 口舌或面部麻木、恶心、心悸、心律不齐 | 附子、川乌、草乌等乌头类 | 立即停药，急诊就医，保留药渣和药液 |
| 皮疹、瘙痒、眼睑肿胀、呼吸困难 | 任何药材的过敏反应 | 立即停药，抗过敏或急诊处理 |
| 剧烈腹泻、脱水、腹痛 | 大黄、芒硝、甘遂、巴豆 | 停药，补液，就医 |
| 头晕、乏力、血压升高、水肿 | 甘草长期大量服用 | 停药评估血压、电解质 |
| 恶心呕吐、头晕、呼吸困难、抽搐 | 苦杏仁、桃仁过量（含苦杏仁苷） | 立即停药并急诊就医 |
| 牙龈肿痛、口腔金属味、乏力 | 朱砂、雄黄等含重金属药材 | 停药并就医检查 |

出现任何严重或持续加重的不适，先停药，再联系开方医师；不要自行催吐或加服其他药物“解毒”。

### 4.7 特殊人群

- **孕妇**：禁用毒性强、药性峻猛及活血破血药；慎用活血化瘀、行气、攻下、温里及滑利之品。用药前必须确认妊娠状态。
- **哺乳期**：麦芽回乳，哺乳期不宜；大黄、芒硝等泻下药慎用。
- **儿童**：剂量按年龄和体重折算，避免使用毒性药材；服药期间家长监护。
- **肝肾功能不全者**：避免含重金属药材及有明确肝肾毒性报道的药材，必要时监测肝肾功能。
- **老年人**：常合并多种用药，注意中西药相互作用，从低剂量开始。

## 五、储存与养护

### 5.1 环境要求

- 置阴凉、干燥、通风处，避免阳光直射。
- 按包装标示的贮藏条件保存；无标示时，常温指 10～30 ℃，阴凉处指不超过 20 ℃，冷处指 2～10 ℃。
- 相对湿度不宜过高，一般控制在 75% 以下；离地、离墙存放，避免直接接触地面和墙面。
- 毒性药材专柜双锁；易串味药材（麝香、冰片、丁香）单独密封；易虫蛀与易霉变药材分区存放。

### 5.2 分类储存

| 类别 | 代表药材 | 主要风险 | 储存要点 |
| --- | --- | --- | --- |
| 根及根茎类 | 黄芪、党参、甘草、当归 | 虫蛀、泛油、霉变 | 密封、干燥、定期检查；当归防走油 |

### 5.3 容器与标签

- 使用玻璃或食品级塑料密封罐；保留原包装标签。
- 分装时注明品名、炮制规格、日期、来源和数量。
- 不使用无标签容器，不与食品、调料混放。
- 按“先进先出”原则使用，定期检查并记录。

### 5.4 家庭储存

- 少量购买，不囤积；开封后尽快用完。
- 密封罐内可放食品级干燥剂，定期更换。
- 枸杞子、红枣、桂圆等易霉变药材冷藏保存；人参、鹿茸冷藏或冷冻并防潮；阿胶密封防潮。
- 冰箱取出的药材先恢复至室温再开封，避免冷凝水导致受潮。

### 5.5 变质处理

出现霉变、虫蛀、泛油、异味、变色或包装胀袋的药材，不得内服，也不得清洗、晾晒后继续使用。普通药材按生活垃圾或厨余垃圾处理；毒性药材按医疗废物或危险废物规定交由有资质机构处理。

### 6.2 十九畏

硫黄畏朴硝，水银畏砒霜，狼毒畏密陀僧，巴豆畏牵牛子，丁香畏郁金，川乌、草乌畏犀角，牙硝畏三棱，官桂畏赤石脂，人参畏五灵脂。

十九畏的“畏”与七情中的“相畏”含义不同：七情之相畏指毒性被另一药减轻，十九畏则是配伍禁忌。

### 6.3 妊娠用药禁忌

- **禁用**：斑蝥、雄黄、砒霜、川乌、草乌、藜芦、胆矾、瓜蒂、巴豆、甘遂、京大戟、芫花、牵牛子、商陆、麝香、三棱、莪术、水蛭、虻虫等毒性强或药性峻猛之品。
- **慎用**：桃仁、红花、牛膝、大黄、枳实、附子、肉桂、干姜、木香、冬葵子、瞿麦等活血化瘀、行气、攻下、温里及滑利之品。
- **原则**：禁用药绝对不用；慎用药权衡利弊，可用可不用者尽量不用；必须使用时严格掌握剂量与疗程并密切观察。

### 6.4 证候禁忌

体虚多汗者忌用发汗力强的麻黄；脾胃虚寒者忌用苦寒伤胃之品；阴虚火旺者忌用温热燥烈之药；湿热内盛者忌用滋腻碍胃之品；表证未解者不宜过早使用滋补药，以免“闭门留寇”。临床应辨证论治，有是证用是药。

### 6.5 饮食禁忌

传统记载：常山忌葱；地黄、何首乌忌葱、蒜、萝卜；薄荷忌鳖肉；茯苓忌醋；鳖甲忌苋菜；蜂蜜忌生葱；土茯苓忌茶。服药期间一般宜忌生冷、油腻、辛辣、腥膻及不易消化之物。
