# 运行总览主页面验收

日期：2026-11-17。

登录后默认主区由问答页改为运行总览，直接展示已有的仿真状态、累计时长、九项指标、批次分布和14类设备。侧栏运行总览切换主区，AI Agent 保留完整问答；数据中心保留四个标签，与主区共享快照读取及刷新。

## 验证结果

- `frontend` 执行 `pnpm typecheck`、`pnpm test` 通过，现有33项回归全部通过。
- `tmp/operations-main-build-*` 隔离副本最终 `pnpm build` 通过，包含 TypeScript 检查和六个静态页面生成；没有覆盖日常开发服务。
- 开发界面和最终生产构建均核验1440 / 390 / 320px：登录后默认运行总览，主区没有聊天输入框；侧栏使用页面语义，Enter切换不打开总览弹窗。手机自动收起导航，页面无整体横向溢出，320px标题完整可见。
- 手动刷新更新真实数据字段的模拟回执；读取失败保留上次快照，无有效快照时显示错误而不补造指标，刷新成功后恢复总览。
- 打开数据中心没有新增独立快照请求，主区和弹窗共享刷新结果；原概览、设备和处方标签可用。两处总览同时渲染时没有重复DOM ID，关闭回到原主页面。
- 切到AI Agent后保留原问答和处方检查入口；创建本地问候回合及草稿，往返切换后仍保留。AI页面且数据中心关闭时，等待超过15秒没有新增快照请求；返回总览重新读取，不自动触发强制刷新。
- 设备分类可展开对应状态和利用率列表；桌面、390px及320px截图已查看，无页面脚本错误。临时生产预览已关闭。
