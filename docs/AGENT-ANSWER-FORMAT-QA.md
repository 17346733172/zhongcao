## 数据口径与能力边界

- `toolCalls` 只展示实际完成的MCP调用，返回摘要/本次耗时/实际数据时间/过期标记，不返回原始工具参数或凭据。
- `charts` 从已校验的批次数量或设备默认秒数转换生成；同名图表保留本轮最后结果。没有有效数据时不展示图表；过期结果保留原时间并提示。设备用时图表使用实际分钟值，保存记录仅说明被修改的一类设备。
- `usage.scope=tool_selection` 为本轮DeepSeek工具选择请求的实际输入/输出Token合计，不包含知识回答生成，也不是全局Token账单。未返回计数或未调用模型时隐藏该行，不使用估算值。
- `answeredAt` 是浏览器收到回答的时刻，显示为北京时间；数据读取时间来自平台结果，两者分别标明。旧消息继续使用已有time。
- 未新增良率、漂移分析、SQL查询、跨批次诊断或全局Token统计能力。本次是回答展示与元数据接入，不改变既有临床辅助审核范围。

本机后端已重新加载，原有模型预热完成，8000后端及3000前端代理健康检查均为ok。前端开发服务已自动更新，新回答使用新增元数据；旧消息兼容展示。
