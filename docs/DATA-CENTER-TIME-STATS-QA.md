# 数据中心按时间统计验收

日期：2026-11-13。

## 功能与统计口径

概览新增「按时间统计」，提供今天、近7天、近30天，均按北京时间自然日并包含今天（不是滚动24小时，也不是本周 / 本月）。每日明细按日期倒序展示，当前设备状态和累计概览保持独立。

| 指标 | 平台历史事件 | 计算 |
| --- | --- | --- |
| 新增处方 | prescription.created | 事件数 |
| 新增批次 | batch.created | 事件数 |
| 完成批次 | batch.completed | 事件数 |
| 配发袋数 | product.dispatched | payload.bags 合计 |
| 新增报警 | alarm.raised | 事件数，含后来解除的报警 |

使用事件 `real_time`，不使用仿真累计秒数；配发不重复累加批次产量。显示实际统计范围、历史同步时间，最早留存日可能只有部分记录，更早日期显示「— / 未留存」。已覆盖日期没有事件时为0，尚未同步的日期标明未同步。全部历史为空或没有成功同步时不给出虚构统计。

平台最早留存事件为 **2026-11-05 21:40:02（北京时间）**。验收时的近30天为10月15日至11月13日，早于11月5日的记录缺失，界面明确提示只汇总已留存事件，无法补造更早月份。数字会随平台运行变化。

## 实现与故障处理

- 鉴权只读接口 `GET /api/data-center/statistics?days=1|7|30`，`refresh=true` 强制同步；权限沿用 knowledge:read，无平台写入。
- 平台按事件类型、ID分页增量读取，避开大量遥测记录；60秒缓存、合并并发、失败退避。同步上限35秒，浏览器等待45秒；客户端仅单轮复用，传输异常关闭并重建，沿用显式代理和认证。
- SQLite 自动增建历史表，保存来源哈希、事件ID / 类型 / 时间 / 数量和游标；不保存患者编号、处方号、追溯码或完整事件载荷。无需新依赖和环境变量。
- 所有类型成功后原子提交；分页、格式、网络失败均保留上次事件、游标和时间。来源隔离；首条事件标识变化时重新同步，避免平台重置后混用旧数据。
- 当前快照与历史同步独立；错误显示具体失败状态，旧的同范围统计保留并标注，不将另一范围数据短暂显示为新结果。
