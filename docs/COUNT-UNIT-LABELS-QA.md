# 处方「枚 / 片」识别与核对

后续更新：仿真上传现已支持枚单位，见[完整上传验收](ITEM-UNIT-QA.md)。下文关于未扩展上传的描述为当时实现范围。

日期：2026-11-12。

用户截图原文包含大枣 3 枚、生姜 3 片，识别结果的数字与单位为空。检查发现表单的常用单位建议和后端规则已包含两个单位，本次补齐提取提示及从已校验原文恢复模型漏填字段的逻辑，并明确单位输入提示。

## 行为

- 仅在该味药的原文摘录已能对应上传文字、包含药名且有唯一明确的数字与枚 / 片组合时，恢复模型遗漏的字段。
- 不使用行号充当剂量；全角数字可规范化为数字。已有字段若与计数不同则不改写，继续执行原有证据校验与人工核对。
- 范围、分数、多个计数量及没有计数原文时保持缺失，不推断克数或药材默认用量。
- 修改单位取消确认；提交检查、返回复查保持原始数字和单位。已打开页面中的旧缺失结果需要重新识别。
- 仅覆盖本草的识别、核对与检查。现有仿真上传协议不支持枚，本次不将枚映射成片，不修改外部平台或服务器。
