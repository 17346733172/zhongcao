## 追加：测试任务口语指令修复

用户原句“帮我下3个测试任务”曾被中药基础资料接收。原因是模块入口漏掉“任务”，而创建数量校验只支持生成/创建/新建。现已同步修复模块路由、任务与仿真批次的工具语义、写入数量识别；支持下/下发/下达/安排，及常用中文、全角数字。

- 真实 DeepSeek + 原有页面 + 隔离 FastAPI/仿真回执：桌面原句、“下发三个任务”“安排3项测试作业”，390px和320px原句，共5项通过。均调用 `test_execution/create/count=3`，返回3个批次编号；没有调用start或中药检索。
- 页面无错误和横向溢出，桌面与320px截图已查看。证据：[结果](../design/mcp-task-language-qa/results.json)、[桌面原句](../design/mcp-task-language-qa/1440-test_execution-1.png)、[320px原句](../design/mcp-task-language-qa/320-test_execution-5.png)。
- 原截图消息没有创建任务；本次验证使用隔离账号/数据库及模拟平台回执，没有代用户在真实平台创建3个任务。修复生效后重新发送原句才会发起实际请求。
