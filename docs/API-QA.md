# 前后端接口检查

日期：2026-10-27。结论：在当前已实现功能、本地环境和下列测试范围内，未发现阻塞性的接口对接问题。未将此结论扩展为所有输入、部署环境或并发场景均无问题。

本记录主体为 DeepSeek 接入前的 14 个 HTTP 操作验收；之后新增 GET /api/ai/status 和 POST /api/chat，当前共 16 个 HTTP 操作，35 项后端测试通过（包含后续字段聚焦和混合来源改动）。DeepSeek 真实服务与浏览器联调见 [专项验收](DEEPSEEK-QA.md)。

## 检查结果

- 后端接口与权限测试：16 / 16 通过。
- 前端 `pnpm typecheck`、`pnpm test`（3 / 3）和 `pnpm build` 通过。
- 在独立前端源码副本上使用 `next build --webpack` 完成生产构建；通过 3107 端口的 Next.js 真实同源代理请求 8107 端口 FastAPI，使用临时 SQLite、随机密码和独立浏览器上下文，无 API 模拟。
- 12 组关键流程通过；捕获 71 次页面 API 响应，无 5xx 和未处理页面异常。401 / 403 为未登录、错误密码、会话撤销、越权和 CSRF 负向检查的预期响应。
- 当前用户服务 3000 / 8000 的健康检查均正常，匿名访问共享资料和基础文档均返回 401。验收后的临时服务已退出，实际账号与资料数据库未改动。

## 路由与前端调用

14 个已实现 HTTP 操作逐项核对通过；前端字段、请求方法、状态码处理和登录 Cookie 与后端一致。

| 接口 | 用途 | 本轮检查 |
| --- | --- | --- |
| GET /api/health | 健康检查 | 前端代理与后端直连均 200 |
| POST /api/auth/login | 登录 | 错误密码反馈、三种角色真实登录、Cookie 经代理生效 |
| GET /api/auth/me | 当前账号 | 已登录读取、未登录 / 会话撤销 401 |
| POST /api/auth/logout | 退出 | 204、旧登录失效、无 CSRF 403 |
| POST /api/auth/password | 个人改密 | 204、重新登录、旧密码与旧会话失效 |
| GET /api/users | 成员列表 | 管理员可读，普通用户 / 编辑员不可读 |
| POST /api/users | 创建账号 | 页面创建、角色字段与输入约束 |
| PATCH /api/users/{user_id} | 角色与启停 | 页面保存、禁用旧登录、启用后可重新登录 |
| POST /api/users/{user_id}/password | 管理员重置密码 | 页面提交、后端会话撤销测试 |
| GET /api/documents | 共享资料 | 三角色读取、刷新后持久化与跨账号共享 |
| POST /api/documents | 保存 MD / TXT | 编辑员真实保存、普通用户 403、输入和大小边界测试 |
| DELETE /api/documents/{document_id} | 删除资料 | 204、其他账号刷新后同步移除、越权拒绝 |
| GET /api/reference-document | 基础资料正文 | 三角色权限测试、桌面 / 手机真实打开全文与 7 张表格 |
| GET /api/reference-document/file | Word 原文 | 同源真实 HTTP 响应 200，返回字节 SHA-256 与原文件相同 |

接口边界测试还覆盖 CSRF、外域请求、登录限流、重复账号、无效输入、会话过期 / 伪造、角色和密码变更撤销、共享资料重启读取，以及并发账号变更时保留有效管理员。

## 真实浏览器流程

本机 Edge：桌面 1487 × 1058、手机 390 × 844、平板 768 × 1024。

1. 未登录跳转，错误密码反馈，管理员登录。
2. 管理员创建编辑员和普通用户。
3. 管理员通过界面保存角色与重置密码。
4. 编辑员上传文本、刷新后读取原文并进行摘录演示。
5. 普通用户读取共享文本，无法调用写资料与管理账号接口。
6. 基础文档真实加载、全文匹配、7 张表格，以及 Word 下载响应内容核对；缺少 CSRF 的退出请求被拒绝且仍保持登录。
7. 管理员停用编辑员后，其原登录失效。
8. 重新启用后编辑员登录并删除资料，其他用户可见删除结果。
9. 个人改密、新密码登录、退出及返回受保护页。
10. 手机登录、只读资料、导航与账号管理，以及平板无溢出。
11. 手机通过真实登录与代理打开基础资料。
12. 无未处理页面异常或业务接口 5xx。

## 尚未实现与验证边界

- 本记录原验收时尚未接入 AI；之后已加入关键词 RAG 与 DeepSeek 模型回答，见 [专项验收](DEEPSEEK-QA.md)。向量语义检索、流式回答、通用 PDF / Word 上传解析与聊天持久化仍待实现。指定 Word 基础文档现已同时用于阅读与检索。
- 本轮检查本地单机业务流程，未做线上 HTTPS / 反向代理部署、并发负载与多浏览器兼容性评测。
- Word 下载验证使用真实同源 HTTP 客户端读取响应并比较字节；受本机无界面 Edge 下载环境限制，未声称浏览器成功将附件落盘。
- 测试客户端出现 Starlette 对当前 httpx 兼容路径的弃用提示，测试全部通过，未发现由此导致的运行接口故障。
