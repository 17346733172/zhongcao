# 数据中心自选日期验收

日期：2026-11-13。

## 使用方式

「数据中心 → 概览 → 按时间统计 → 自定义」可选择开始日期、结束日期并点击「查询」。包含起止两天，可查同一天，一次最多366天，结束日不得晚于北京时间今天。修改日期只更新草稿，提交后才更换统计；页面标明实际查询区间。今天 / 近7天 / 近30天继续保留，刷新和独立重试沿用当前已提交范围。

汇总和每日明细继续显示新增处方、新增批次、完成批次、配发袋数、新增报警；当前设备和累计概览独立。历史留存不足、已覆盖但无事件、同步失败有不同反馈，不补造统计。

## 接口与范围

- `GET /api/data-center/statistics?start_date=2026-11-06&end_date=2026-11-10`，也支持 `refresh=true`。
- 两个日期成对提交，与 `days` 互斥；不提供参数时仍默认近7天。响应 `days` 为实际天数。
- 前后端均校验空日期、起止倒置、未来日期及超过366天；服务端还验证非法日期与冲突参数，在读取平台前拒绝无效范围。
- SQL 以北京时间开始日零点为包含下界、结束日次日零点为排除上界，并限定到真实同步时间，确保结束日完整包含、后一天不混入。
- 不改动历史同步或表结构，复用现有持久化事件、增量同步、显式代理、鉴权和35秒同步上限，无新增依赖或配置。
- 前端缓存按起止日期区分；新查询不显示另一范围的数字，失败时只保留同范围旧结果。
