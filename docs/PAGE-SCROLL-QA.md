# 主页面统一滚动验收

日期：2026-11-18。

按用户截图取消回答区域内外两层纵向滚动。`page-scroll.css` 让主栏成为唯一的主内容纵向滚动容器，聊天包装与总览内容自然展开，保留宽图表横向滚动。标题置顶、输入区底部可达，输入区背景遮挡其后的正文。

`KnowledgeWorkspace` 同步调整新回答定位、页面切换位置记录和标题/输入区实际高度留白。滚动留白只用于正文控件和图表定位，不作用于固定导航或输入控件；导航及弹窗关闭时恢复焦点但不额外滚动，避免手机返回聊天后跳动。弹窗/手机导航打开时暂停主栏背景滚动。

浏览器验证4种窗口：1440×1000、390×844、320×844、1280×600，全部通过：

- 活跃主内容纵向滚动容器只有 `.main-panel`，文档高度等于视口高度，window.scrollY为0，没有第二条页面纵向滚动条。
- 65段长回答及连续两轮回答完整展开，可滚到末尾；鼠标在正文滚动时主栏移动，回答包装scrollTop仍为0，不是仅隐藏其滚动条。
- 标题/输入区可见，输入区背景不透明；定位控件时的底部留白与实际输入区高度一致，无横向溢出。
- 总览与聊天切换恢复各自阅读位置，草稿保留；手机导航关闭不触发额外滚动。
- 原文弹窗可读、可关闭；打开时主栏滚动锁定，关闭后恢复；图表原始数据展开仍只有主栏纵向滚动，无pageerror。
