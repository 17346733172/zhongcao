- `frontend` 的 `pnpm typecheck`、`pnpm test` 通过，33项现有回归全部通过。
- `tmp/active-pots-build-*` 隔离副本的 `pnpm build` 通过。副本沿用此前验收的临时 Turbopack 根目录及单 worker 设置，不影响开发服务或修改项目构建配置。首次因共享依赖超出临时根目录失败，修正临时配置后通过；构建仍有此前已记录的 Next.js 安全升级提示，本任务未调整依赖。
