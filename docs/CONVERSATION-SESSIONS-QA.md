# AI Agent 会话窗口验收

日期：2026-11-19。

按用户参考图，在原功能导航与聊天区之间增加独立白色会话栏：深蓝矩形「新会话」、历史会话列表、轮数、当前选中状态、空提示与页面保留说明。仅显示真实产生的本页对话。1100px 及以下改为页头「会话」入口打开原生窗口。

## 行为验证

使用项目已有 Playwright 与本机 Chrome 的隔离上下文、模拟账号及 API；未调用真实模型或写入账号、处方及仿真平台。1440、1280、1100、768、390、320px 六种宽度（高度均为900px）全部通过：

- 空会话提示、新会话按钮、历史列表与当前选中态正常；新建后清空当前回答、草稿及错误，保留旧会话。
- 两个会话之间恢复 / 继续追问，仅发送各自历史；新会话请求为空历史，不发生上下文串线。
- 正在生成时切换会话，浏览器取消等待；旧请求完成后不会覆盖当前会话或追加历史，输入立即恢复可用。
- 请求失败保留草稿，不增加虚假历史；新建后错误清除。
- 窄屏窗口支持关闭、Escape、焦点返回、Tab 循环；桌面收起 / 展开功能导航时会话栏仍正常。
- 长回答保持主栏单一纵向滚动，无整页横向溢出；运行总览往返保留会话，刷新清空与界面说明一致。无页面异常。
